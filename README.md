# Local Multi-Agent System (Windows / Ollama)

ローカル環境（Windows、Python、Ollama）で動作する、ファイルベースの自律型マルチエージェント対話システムです。学术知識とビジネス視点を持つエージェント同士が、共有ファイル（`shared_memo.txt`）を介してラウンド形式で対話・議論を行います。

## 🛠 前提環境 (Prerequisites)

- **OS**: Windows
- **Python**: 3.x
- **Ollama**: ローカルでLLMが実行できる環境
- **使用モデル**: `Llama-3-ELYZA-JP-8B-GGUF` （必要に応じてコード内のモデル名を変更してください）
